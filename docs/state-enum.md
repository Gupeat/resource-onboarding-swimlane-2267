## 2. 状态流转总览

```text
申请中 ──提交审核──▶ 审核中 ──上架──▶ 已上架 ──暂停──▶ 已暂停
   │                   │                 ▲               │
   └──缺件──▶ 待补件 ──┘                 └──整改通过─────┘
   │                   └──拒绝──▶ 已拒绝
   └──撤回/前置拒绝──▶ 已拒绝

已上架 ──12 个月复审不通过 / 主动退出 / 严重违规──▶ 已下架
已暂停 ──整改不通过 / 严重违规──▶ 已下架
```

说明：`已拒绝` 与 `已下架` 为终态；如需重新合作，按新申请单重新走 S01–S10，不直接复活旧记录。

## 3. 暂停触发条件

任一条件成立即进入 `已暂停`（S12 暂停并复查）：

| 编号 | 触发条件 | 判定规则 | 责任角色 |
|---|---|---|---|
| P1 | 滚动平均分 < 3.0 分 | 仅统计有效评价；建议在有效评价 ≥ 3 条时启用该阈值（建议值，待客户确认）。 | 运营 |
| P2 | 收到有效投诉 | 投诉需与资源服务质量相关，且有撮合记录或沟通记录佐证；由运营核实后计入。 | 运营 |
| P3 | 资质或协议到期未更新 | 补件期（建议 10 个工作日）内未更新，先暂停再复查（实现选择，待客户确认）。 | 会员经理 |

**评分阈值说明**：`平均分 < 3` 为建议值，图中标注「待客户确认」；有效评价的最小条数（建议 ≥ 3 条）同样待确认。评分只统计有效撮合后的评价（1–5 分整数）。

## 4. 下架触发条件

任一条件成立即进入 `已下架`（S14 下架并归档）：

| 编号 | 触发条件 | 判定规则 | 责任角色 |
|---|---|---|---|
| D1 | 12 个月定期复审不通过 | 复审覆盖资质、协议、评分、投诉；未通过则下架（周期为建议值，待客户确认）。 | 运营 |
| D2 | 暂停后整改不通过，或发现严重违规 | 严重违规包括虚假资质、重大投诉、违反合作协议；直接下架并归档。 | 运营 / 管理层 |
| D3 | 资源方主动退出或协议终止 | 资源方提交退出申请，确认无未结撮合后下架。 | 资源方 / 运营 |
| D4 | 资质失效且无法补件 | 证照过期、主体注销等，补件期内无法恢复的，下架处理。 | 会员经理 / 运营 |

## 5. 恢复规则

暂停 → 整改通过（运营确认，必要时管理层复核）→ 已上架；重新开始 12 个月复审计时。

## 6. 待客户确认

- 评分阈值 `3` 分与有效评价最小条数。
- 复审周期 `12` 个月；是否按资源类型分档。
- 暂停后的整改期限（建议 10 个工作日）。
- “有效投诉”的最终判定人（当前设计为运营，必要时管理层复核）。
